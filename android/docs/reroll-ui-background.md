# 刷开局界面与后台运行

“刷开局设置”位于主界面右上角，与“策略设置”并列。难度、目标公会、路线、Boss、次数和撤退选项统一收进该设置页；主界面不再把这些配置拆成多个卡片。设置按账号保存在本机，切换账号独立加载；编辑后点保存才生效，取消不覆盖原设置。恢复默认只修改弹窗草稿，仍需保存。

新版主流程只保留“登录账号并读取当前开局”和“自动执行”两个步骤。单独刷开局入口放在“辅助工具”中，适合只想重置开局、不运行完整批量流程的情况。若第一步已经读取到符合首个批量目标的开局，自动执行会直接复用该开局；后续轮次仍按原有刷取规则运行。

新配置默认勾选“刷到出”和“允许彻底撤退当前开局”；已经保存的关闭选项保持关闭。启用撤退时，每次启动前另行确认风险。只在既有工作流能够确认当前开局不满足目标时撤退，状态不确定时仍停止核对，不绕过检查点。

网络刷取使用独立的 dataSync 前台服务，不启动截图、识别或游戏点击。离开页面、切换其他应用后可继续运行；通知显示公会、难度、耗时和进度，提供停止按钮，点击通知返回刷开局页。开始前要求通知权限和对应通知频道开启。任务开始时冻结配置，运行中禁止修改；切换账号会取消原任务。

验证码、完成、错误和停止会保留结束/待处理通知。验证码需要返回应用处理。进程被系统终止后不自动重启或重放刷取；重新启动仍按现有工作流核对服务端开局和本地检查点。应用自行在单次运行 5 小时 55 分钟时停止，并处理 Android 系统更早发出的前台服务超时回调，因此“刷到出”不代表能够绕过系统限制无限后台运行。省电策略、网络和厂商进程管理仍可能中断任务。

本次本地验证覆盖设置默认值、按账号保存和重建、取消草稿、无效配置、冻结配置、通知文本，以及既有刷取工作流、当前开局判定和路线策略；构建 debug APK。没有启动真实刷取，也没有操作模拟器，后台实际运行和界面效果留待用户验收。
