# 节点类型冲突与自恢复（2026-09-14）

节点类型冲突恢复不再只处理 LINK ↔ RELIC。只要保存路线已经确定下一节点，视觉分类与路线语义冲突时，恢复层会对所有节点类型统一处理。

自动覆盖仍有两条安全路径：其一是 FULL_COLUMN / PARTIAL_COLUMN / REACHABLE_SUBSET 等有序拓扑已经可靠绑定目标；其二是当前路线图明确只有一个可达后继，并且当前画面也只有一个稳定可点击冲突框。仅有 SINGLE_TARGET 且当前节点存在多分支时，不会因为连续几帧相同就直接覆盖类型。连续三帧稳定后仍进入原有节点点击稳定性、移动确认和目标页面确认流程，不会用路线推断替代游戏确认。

冲突持续但证据仍不足时，不再无限观察或连续向同一方向大幅滚图。节点页会按“中心→一侧→中心→另一侧→中心”的节奏执行小幅左右微调，避开当前节点框，制造新的背景与模板证据后重新分类。目标按地图几何应已在画面、最终 Boss 底座暂时无法定位、节点多次点击未获确认，以及整区扫描到边界后仍未识别目标，也会进入同一局部恢复。
