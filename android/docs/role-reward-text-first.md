# 三选一文字优先与获得角色直接入库

2026-09-15

三选一页同时提交三个姓名区域的异步 OCR。完整姓名或别名在角色库中唯一匹配时直接采用，包含服装后缀；不需要先运行头像匹配。文字为空、歧义、残缺或 OCR 超过 2.5 秒未返回时，仅对相应槽位运行头像匹配及原有文字辅助校验。OCR 和可靠头像结果按姓名区域指纹缓存，离开三选一后清理缓存，并隔离过期 OCR 回调。左侧姓名区域恢复完整首字。

角色库里 91 个服装家族中有 88 个同时存在不带后缀的本体角色，而卡片上服装后缀单独占一行。OCR 结果恰好等于某个存在服装变体的本体名时，不允许单凭文字绕过头像：先对该槽位跑头像匹配，头像家族一致才采用文字身份，不一致则以头像结果为准，头像未定则保持未定。没有服装变体的名字和带完整后缀的名字仍直接采用。

取消三选一的三帧身份稳定等待，也不再叠加通用两帧等待；仍要求页面、候选身份和按钮满足现有点击条件。候选、已拥有角色、守备层数和按钮位置未变化时复用选角建议，已提交的同一组三选一不重复计算。新增 `roleRewardDecisionMillis` 日志，区分策略计算与图像识别耗时。

仅在手势执行成功后，将所选角色写入当前局角色库，供后续选择直接使用。此批三选一后的角色加入页面跳过身份识别，仍识别加入页与关闭按钮并直接关闭。离开奖励批次或停止会话后清除跳过标记；商店背景下的加入页面强制保留普通识别。点击被拒绝不入库，写库失败时保留加入页识别以便补录。

页面停留按本帧时间戳至下一帧时间戳累计，包含识别、策略、采集间隔、动画及可能的人为等待，并非独立测量的纯识别耗时。

123336 中四段三选一分别停留约 28.6、29.9、29.3、32.7 秒；相邻有效选角帧常相隔 9～11 秒，而帧处理仅约 0.4～0.9 秒。结合原先每帧都调用选角策略、再等待三帧的代码，重复策略计算是明显可疑的额外开销；旧日志没有独立的策略计时，不能把全部间隔都归因于某一个函数。

三选一存在明显停顿，但这些日志不能证明其全程耗时第一。123336 同窗口地图累计识别约 211.7 秒，编组约 87.0 秒，均超过三选一的 12.7 秒；地图与编组页面停留也分别约 214.1、191.5 秒。最新的 174617、205754 两包没有三选一历史帧，主要记录编组与战斗。

上述地图耗时来自旧版本。当前工作区已接入阶段一的 NodeSearchHint、L1/L2/L3 降级与独立视口签名；用户报告 LINK fixture 搜索窗口由 2266 降至 614。旧日志的性能排名不能直接代表阶段一优化后的实机结果。本次修改保留这些节点优化。
