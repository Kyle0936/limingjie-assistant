# 商店印记直接加入角色

随机职能印记可能在购买后直接显示角色加入弹窗。该弹窗属于商店奖励，不要求经过初始邀请或奖励选人页。

处理入口增加来源判断：已识别 CHARACTER_JOINED 且两分钟内成功执行过印记购买确认，或至少两个商店背景锚点达到 0.65，则直接交接奖励处理。购买来源独立于购买弹窗临时状态保存，新的执行会话会清空。商店背景判断也支持从用户截图所示的已打开弹窗中途恢复。

复用已有角色加入识别、名单记录和关闭逻辑；返回商店后继续处理商品。无购买来源且无明确商店背景的加入页仍按原入口规则处理。

回归包含用户的千歌（礼服）加入截图，使用应用模板完成页面识别及来源判定，以及来源过期、弱背景和初始邀请隔离检查。
