# 遭遇攻略条件尽力满足

2026-09-13：EX / Boss 共用的遭遇攻略条件改为评分偏好。角色不足或能力数据缺失不再让首次推荐、候选阵容搜索、失败重试及 EX 换治疗兜底返回不可用。

每个条件按已确认人数 / 目标人数获得加分，达到目标后封顶。未知能力仍为未知，不补写或推断为满足条件。大角色池预筛选也使用相同偏好。推荐原因优先显示本队未满足的条件、确认人数和资料缺失人数。

原有队伍结构校验、角色身份确认、失败阵容去重和有效效果角色保护继续适用。攻略中的 `hard` 字段仅保留原始语义元数据，不再用于淘汰候选队伍。

回归覆盖能力缺失、已确认人数不足、角色充足时优先补齐条件、首次推荐、普通重试以及第二次 EX 失败换治疗。
