# 战斗前选人界面模板

这组模板对应“进入战斗前”的实时队伍编组界面，来源于模拟器现场截图：

- 截图：`通关视频/分析输出/ADB只读回归/当前选人界面_现场.png`
- 画面：1920x1080（游戏横屏逻辑分辨率）
- 页面标题：`队伍编组`
- 页面特征：元素筛选栏、`当前的成员`摘要、`取消`、`战斗开始`
- 角色卡片行存在两种已验证布局：筛选栏下方直接显示（约 y=243），或展开角色名搜索栏后下移（约 y=356）；运行时会按卡片内容自动选择布局。

| 文件 | 用途 | 原图裁剪区域（x,y,w,h） |
| --- | --- | --- |
| `battle_team_selection_header.png` | 页面主标题/蓝色标题栏 | 40,35,1840,90 |
| `battle_team_selection_filter_bar.png` | 元素筛选栏 | 70,140,1040,80 |
| `battle_team_selection_current_members_summary.png` | 底部成员摘要固定标签 | 75,748,1100,60 |
| `battle_team_selection_cancel_button.png` | 取消按钮 | 1285,850,270,110 |
| `battle_team_selection_start_button.png` | `战斗开始`按钮 | 1565,850,270,110 |

角色卡片、生命值/攻击力数字和成员数量会随队伍状态变化，因此没有把具体角色头像制作成页面识别模板。识别时建议以标题栏和`战斗开始`按钮为主，筛选栏或底部摘要作辅助确认。

这组模板已写入 `vision.json` 和资源包清单，并接入入口识别运行时。角色卡片不作为整页锚点：运行时会独立识别上方可见卡片、底部当前成员、属性筛选状态和右侧滚动条；未覆盖到图标素材的角色会返回“未收录”，不会影响页面识别。
