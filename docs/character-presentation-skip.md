# 角色展示过场跳过

## 问题

在黎明界选择角色并确认后，客户端会短暂显示全屏角色展示。展示图覆盖了黎明界的标题、地图、按钮和底栏，因此它不是可被常规模板可靠分类的页面。此前识别器会将其报告为 `UNKNOWN`，并按默认安全策略停止一切点击，导致流程停在展示页。

## 受限跳过规则

此项目不会对所有 `UNKNOWN` 页面点击。只有同时满足以下条件时，才把画面作为可跳过展示处理：

1. 前一帧已可靠识别为 `INITIAL_CHARACTER_SELECTION`（初始选角页）；
2. 当前帧为 `UNKNOWN`；
3. 当前帧的所有已知黎明界锚点分数都低于 `0.25`，证明黎明界周边 UI 已被全屏画面覆盖。

满足条件后，流程复用既有“角色获得动画”驱动，在屏幕中央偏下的安全区域点击。该驱动仍有 600 ms 间隔、40 次点击上限和 30 秒超时；一旦出现角色加入页、道具页或节点页，正常页面状态机会立即接管。

## 为什么不用单独的人物图片模板

展示角色、皮肤、特效和版本会不断变化，维护完整图片目录既慢又容易漏掉。这里真正稳定的视觉信号是：它紧随确认选角出现，并遮住全部黎明界 UI。使用“已知安全前置状态 + UI 完全消失”的组合，能覆盖新角色展示，同时避免把普通未知弹窗变成自动点击。

## 测试

`LabyrinthEntryActionPlannerTest` 包含从初始选角页进入无锚点 `UNKNOWN` 帧的回归测试，断言产生的是受限的 `ADVANCE_CHARACTER_ACQUISITION` 动作，而不是通用 UNKNOWN 点击。
